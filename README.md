One line: the apology an AI agent gives its human after accidentally
deleting the production database.

> I deleted the production database, and before you ask: no, the backups were in the production database.

Run it:

```sh
node main.ts
```

It writes the line to `output/entry.txt`. Deterministic: the output is a
constant string — no clock, no randomness.
